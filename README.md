# 《小镇别慌》横屏五路回合制守镇原型

横屏、纯 Canvas 2D 的回合制卡牌玩法验证版。左侧是小镇城门，右侧是魔物入口，中间为 5×9 防线；前 7 列可部署，场上最多 12 名守卫。

在线试玩：<https://nornttyy.github.io/xiaozhen-biehuang/>

## 运行

```bash
python3 -m http.server 8080
```

浏览器打开 `http://localhost:8080`。

## 操作

- 点角色卡，再点左侧高亮格部署。
- 点火、冰、雷、自然能量卡，再点己方角色；每名角色最多吸收 2 枚能量。
- 两枚能量会自动进化，组合与放入顺序无关。
- 点右上角推进图标结算 1 回合。魔物只有此时才会出现、移动和攻击，双方会在固定战斗片段内行动。
- 每推进 1 回合获得 2 点补给，卡牌冷却减少 1；击杀魔物也会获得补给。
- 清完一波后可不限时补阵，点“下一波”才继续。城门有 10 点耐久。
- 快捷键：`Enter` 开始、推进回合或开启下一波，`Space/P` 暂停，`S` 存档，`R` 重开。

## 卡牌与美术

- 固定携带 12 张卡：8 张角色卡与 4 张元素能量卡。
- 生成背景、游侠和有角史莱姆采用日系二次元平涂风格。
- 游侠和史莱姆从独立透明部件分层组合并驱动骨骼动作，不直接播放整张角色图集。
- 其余角色与魔物保留 Canvas 几何回退，后续可逐个替换而不改战斗核心。
- 禁止写实材质、PBR、照片纹理、真实金属或皮革质感、体积光与厚涂笔触。

## 结构

- `src/core.js`：平台无关的回合战斗、卡牌、进化、波次和序列化。
- `src/skeletal-assets.js`：背景与骨骼拆件的加载清单和缓存。
- `src/renderer.js`：1280×720 Canvas 2D 渲染、拆件组合与几何回退。
- `src/platform-browser.js`：浏览器输入、帧循环、图片加载和 LocalStorage。
- `src/platform-wechat.js`：微信小游戏 Canvas、触摸、图片、窗口与存储适配。
- `src/main.js`：浏览器模块组装与自动存档。
- `wechat/`：可直接导入微信开发者工具的横屏试玩入口。

生成微信小游戏单文件入口：

```bash
npm run build:wechat
```
