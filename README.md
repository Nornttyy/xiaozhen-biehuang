# 《小镇别慌》美少女消消乐

[在线试玩](https://nornttyy.github.io/xiaozhen-biehuang/)

横屏 2D 点消游戏：7×6 棋盘、四位美少女伙伴、10 个短关卡。点击两个以上正交相连的同色方块即可消除、掉落补位并发动攻击；思考时战斗暂停。

## 玩法

- 每关 25 步，击败 3 只魔物过关。步数耗尽或生命归零可直接重试。
- 火、冰、雷、自然为对应伙伴充能，累计消除 10 枚自动释放技能。爱心恢复生命。
- 4 连生成横排消除块，5–6 连生成九宫格炸弹，7 连以上生成同色全消彩虹块。点击特殊块即可触发，命中的特殊块会连锁。
- 魔物头上的数字是距离攻击还剩几次操作，冰技能可延缓攻击。击败魔物后的溢出伤害会传到下一只。
- 每关有 2 次免费重排和 2 次免费小锤；小锤选择后点一个方块使用。无可消组合会自动重排。
- 点击顶部关卡按钮重玩已解锁关卡，星级与当前进度自动保存。新存档与旧塔防存档分开保存。
- `Space/P` 暂停，`Esc` 关闭选关或暂停，`Enter` 继续，`R` 重开本关。

## 运行与验证

```bash
npm start
# 浏览器打开 http://localhost:8080
npm run build:wechat
npm test
```

微信开发者工具导入 `wechat/`；正式微信发布仍需配置自己的 AppID 并完成真机测试。GitHub Pages 为无依赖静态网站，推送 main 后更新。

## 结构与素材

- `src/puzzle-core.js`：连块、重力、特殊块、技能、魔物回合、10 关进度与存档校验。
- `src/puzzle-renderer.js`：粉彩点消界面、角色卡面、战斗与消除动画。
- `src/puzzle-runtime.js`：网页与微信共用入口逻辑、逐步自动存档。
- `src/platform-browser.js` / `src/platform-wechat.js`：各平台输入、画布、图片加载与存储。
- `src/skeletal-assets.js`：背景、4 人头像图与 24 个骨骼部件，共 26 个运行素材。
- `src/core.js` / `src/renderer.js`：保留上一版塔防实现与可复用的游侠、史莱姆拆件绘制；当前入口使用 `PuzzleGame`，不启动塔防规则。
- [头像素材与完整提示词](assets/generated/puzzle/README.md)。头像仅用于 UI；战斗使用拆件动画。全部采用二次元平涂，禁止写实材质或 PBR。

首版固定四位伙伴与三种史莱姆外观；角色抽卡、换装和元素进化不在这一版消除玩法中。
