# 二次元骨骼素材包

这些素材由内置图片生成工具制作，并按运行时骨骼插槽拆分。正式运行只加载 `parts/` 中的透明 PNG，`atlas-anime-v2.png` 是可追溯的源图集，不会作为整张角色贴图使用。

## 文件

- `battlefield-anime-v2.png`：1280×720 五路战场背景。
- `ranger/parts/`：游侠的头、前后发、躯干、前后上下肢、弓、箭袋、披风和箭特效，共 16 件。
- `slime/parts/`：史莱姆的身体、脸、双角、双臂、魔核和接触阴影，共 8 件。
- `scripts/crop-skeletal-assets.py`：从源图集重复生成独立部件。

## 生成方式

模式：内置图片生成工具（非 CLI）。

场景最终提示要点：保持五路战场构图，转换为扁平日式动画背景；使用清晰轮廓、纯色色块和两档硬边阴影；禁止写实/PBR、真实材质纹理、颗粒、厚涂、真实反射、体积光、景深和 3D 渲染。

游侠最终提示要点：保持 4×4 的 16 件拆件布局与透明通道；头、前后发、躯干、前后上下肢、弓、箭袋、披风和箭特效全部隔离；只用二次元描边、平涂与单档硬边阴影；禁止写实皮革、金属、布料和皮肤材质。

史莱姆最终提示要点：保持 4×2 的 8 件拆件布局与透明通道；身体、脸、双角、双臂、魔核和阴影全部隔离；只用紫色平涂、单档硬边阴影与简化高光；禁止真实果冻、折射、次表面散射和 3D 光泽。

## 生产约束

- 禁止把源图集作为整个人物贴图接入游戏。
- 新角色优先复用同一骨架与插槽命名。
- 元素进化通过插槽、换色和独立特效层表现，不复制整套动画。
