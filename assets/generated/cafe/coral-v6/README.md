# Coral v6 分层骨骼导入模板

成年咖啡店角色，共 28 个独立 PNG，已由 `scripts/export-cafe-parts.mjs` 导出到 `parts/{名称}.png`，原图保留。逐一读取 PNG 文件头确认：28 个文件均有有效尺寸、8 位 RGBA 通道；宽度为 86–364 像素，高度为 18–376 像素。身体图集为 4×4，头部及表情图集为 4×3，逐行顺序见 `rig.json`。脸型保持成年人的椭圆比例，表情偏温暖可爱；空白脸底不得烘焙眼睛、眉毛或嘴巴。

骨骼链为「骨盆→大腿→小腿→鞋」和「躯干→上臂→前臂→手」。裙子与围裙固定在骨盆，衣身随躯干，袖子随上臂。虚拟头节点统一带动脸底、后发、左右侧发与刘海；眼、眉、嘴挂在脸底上，分别替换。左/右指中立正面姿势的画面左/右。

提供 neutral、happy、blink、talking 四套独立表情组合；每个五官槽位同时只显示一个变体。托盘与杯子为可选配件，初始隐藏，分别跟随左手和托盘，端盘姿势需单独校准。

`rig.json` 是导入模板；其中所有轴心、父级挂点、尺寸和遮挡顺序均为**初始估算，尚未对齐验证**。坐标按对应 PNG 的完整画布归一化，透明留白也计入尺寸；裁边或更改留白后必须重校。`size` 是参考舞台上的布局提示，不是已测量比例，也不表示应拉伸图像。

实际网页预览使用项目中的 [`src/cafe-rig.js`](../../../../src/cafe-rig.js) 及其单独设置的像素变换，不读取本模板的归一化轴心。网页预览的动作与表情检查不能代替本模板的几何校准。

图集和独立素材已就位；生成图边缘仍有彩色残边，不能称为已完全清理透明通道。原始膝部带有描边封口，拼接时可能仍能看到接缝。此模板的关节、衣物遮挡、表情位置和动画尚未通过视觉验证；文件头及 JSON 结构检查仅证明导出文件与规格结构有效。
