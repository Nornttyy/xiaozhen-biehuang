# 美少女消消乐 · 微信小游戏入口

先在上一级目录运行：

```bash
node scripts/build-wechat.mjs
```

然后用微信开发者工具导入本目录。`touristappid` 仅用于本地试玩，发布前替换为实际小游戏 AppID。

入口使用 `wx.createCanvas`、触摸事件、图片预载和同步本地存储；消除核心与浏览器版本共用。构建会复制背景、四人头像卡面和 24 个独立骨骼部件，不会复制骨骼源图集。每步自动存档，采用独立的消除游戏存档键。

首版包含 7×6 点击连块、特殊块连锁、角色充能、10 关进度与横屏适配；正式微信发布前仍需真机确认显示、加载和触摸。
